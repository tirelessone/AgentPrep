# 内容与许可证策略

## 可接收内容

- 仓库贡献者原创且同意按仓库许可证发布的内容。
- 明确允许复制、修改和再分发，并满足署名及相同方式共享等条件的内容。
- 仅用于本地私有导入、不进入 Git 或公开构建的用户自有内容。

## 禁止内容

- 来源不明、许可证缺失或授权范围不清的公开题库。
- 通过页面抓取、截图转录或模型改写来规避原内容授权限制的内容。
- 牛客、ky408、CodeBrick 等没有明确再分发授权的题目与解析。

## 入库流程

1. importer 读取外部格式，但不复用来源项目的应用代码。
2. 原始来源标识、版本、许可证、转换工具和校验摘要写入 manifest。
3. 新内容先进入 `content/quarantine`，默认 `reviewStatus: unverified`。
4. 人工核验题意、答案、解释、许可证与来源后，才可标记为 `reviewed`。
5. 发布构建只接受 schema 有效且审核状态为 `reviewed` 的内容。

AI 生成题的 `source.kind` 必须为 `ai_generated`，必须记录模型与生成批次，且不得由生成程序自动标记为 `reviewed`。

## 撤回与修订

来源授权变化、权利人请求或内容错误均可触发撤回。题目 ID 保持稳定，manifest 记录废弃版本和原因，学习记录保留但不再展示被撤回正文。
