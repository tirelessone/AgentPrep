# ADR 0005：外部内容必须经过隔离与人工晋级

- 状态：Accepted
- 日期：2026-09-19

## 背景

外部题库的格式、质量和授权都不可信。直接复制到发布目录会混淆原创边界，也无法证明转换和审核过程。

## 决策

Importer 只接受显式来源版本和再分发许可证，只能写入 `content/quarantine`，并将状态固定为 `unverified`。独立人工审核命令记录审核者和许可证证据后才能生成发布 manifest；该命令明确拒绝 `ai_generated` 内容。发布 manifest、溯源报告和第三方声明都由 CI 重建校验。

## 后果

外部内容至少经历两次显式操作，且不会因为转换成功自动获得发布资格。来源授权不清时流程必须停止。AI 内容若未来需要发布，必须走与生成器分离的专门人工编辑流程。
