# ADR 0004：Tutor 资源预算

- 状态：已接受
- 日期：2026-09-19

## 背景

Tutor 是无需账号即可访问的可选在线能力。仅有请求超时不能限制超长上下文、重复请求或模型输出长度，因此公网部署会面临不必要的延迟、内存占用和 provider 成本风险。

## 决策

在请求进入 provider 前实施四层边界：Zod 字段长度上限、Fastify 请求体上限、按来源 IP 的进程内限流，以及 OpenAI-compatible 请求的输出 token 上限。所有阈值都由 Server-only 环境变量配置，并带有安全默认值与允许范围；无效值回退到默认值。

这些保护不引入账号系统，也不改变 local-first 学习闭环。公网部署还必须在可信反向代理配置独立限流与成本告警，不能把单进程内存计数器视为分布式配额系统。

## 后果

极端长输入会在模型调用前以 `400` 或 `413` 拒绝；超过频率的请求会返回 `429`。多实例部署时每个实例的计数彼此独立，因此当前方案只提供第一层防护，不承诺全局精确配额。
