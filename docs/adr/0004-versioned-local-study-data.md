# ADR 0004：版本化本地学习数据与可移植备份

- 状态：Accepted
- 日期：2026-09-19

## 背景

学习闭环必须在无后端时工作，并能在 schema 演进时保留用户记录。备份不能把题库答案或服务端秘密混入用户数据。

## 决策

使用 Dexie 管理 `agentprep` IndexedDB。逻辑版本 2 包含 settings、attempts、favorites 和 reviews 四张表；升级沿用 Dexie 的增量版本迁移。备份 schema 独立版本化，只导出四张用户状态表，导入前实施 2 MiB 限制、JSON 解析和 Zod 校验，并在事务中原子替换。

## 后果

题库内容版本与学习数据版本可以独立演进。恢复操作会覆盖当前设备的学习状态，因此 UI 必须明确提示；未来 schema 变更需要同时增加迁移测试和备份兼容测试。
